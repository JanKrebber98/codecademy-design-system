# Design System – Codecademy-Projekt

> **Hinweis:** Dies ist ein Übungsprojekt aus dem Kurs von [Codecademy](https://www.codecademy.com/).
> Die Aufgabe („Build a Style Guide / Design System“) stammt von Codecademy, die Umsetzung ist meine eigene.

Ein Style Guide bzw. Design System für eine Website. Es dokumentiert das visuelle Vokabular und die
wiederverwendbaren Bausteine an einem Ort, damit eine Website einheitlich aussieht und andere
Entwickler:innen eine gemeinsame Referenz haben.

## Inhalt

| Seite | Was sie zeigt |
|---|---|
| [Übersicht](index.html) | Einstieg mit Karten zu allen Bereichen |
| [Farben](farben.html) | 8 Farben mit Name, Farbfeld, CSS-Wert (hex, rgb, rgba, hsl, hsla) und Verwendung |
| [Schriften](schriften.html) | Playfair Display, Source Sans 3 und JetBrains Mono (Google Fonts) mit allen Stilen |
| [Textstile](textstile.html) | Hauptüberschrift, Zwischenüberschrift, Unterüberschrift, Fließtext, Link, Zitat, Bildunterschrift |
| [Abstände](abstaende.html) | Abstandsskala und Breakpoints |
| [Ecken & Schatten](formen.html) | Eckenradien und Schattenstufen |
| [Komponenten](komponenten.html) | Buttons, Formularfelder, Hinweisboxen, Badges, Karte und Breadcrumb |

## Umgesetzt

- Pflichtteile der Aufgabe: Farben, Schriften und Textstile
- Erweiterungen: zusätzliche Komponenten, eigene Seite pro Bereich mit Navigation und Breadcrumb, responsives Layout für Tablet und Handy
- Alle Werte als CSS-Variablen in [`styles.css`](styles.css) (Farben, Schriften, Abstände, Radien, Schatten)

## Verwendete Technik

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Media Queries)
- Google Fonts

## Ansehen

Repository klonen und `index.html` im Browser öffnen – es ist kein Build-Schritt nötig.
